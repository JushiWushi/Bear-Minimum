
# Bear Minimum 🐻

**For executive dysfunction, even on your worst days.**

Bear Minimum is a low-friction second brain for managing everyday life, designed to reduce mental load instead of demanding more of it.

Rather than focusing on maximizing productivity, Bear Minimum aims to make it easier to organize thoughts, remember responsibilities, and figure out what to do next.

## Philosophy

Most productivity tools assume you already have the energy and executive function to maintain a system.

Bear Minimum is built around a different idea: **the tool should work for you, not the other way around.**

- **Design for the worst days.** Good days are a bonus.
- **Capture now, organize later (or never).** Getting something out of your head is enough.
- **No unnecessary commitments.** No forced categories, deadlines, streaks, or pressure to stay consistent.
- **Make it easy to return.** Stop halfway, disappear for months, and pick up where you left off.
- **Reduce mental load.** Every feature should remove more effort than it adds.

## Planned Features

### To-Do List
A low-friction to-do list with **Must / Should / Could** priorities. Plan what needs doing, carry unfinished tasks forward, or simply leave them behind. No pressure to complete everything.

### Calendar
Keep track of deadlines, appointments, and events with quick, low-friction scheduling and bulk entry.

### The Pile
A searchable brain dump for thoughts, ideas, links, and anything else you don't want to lose.

Capture now, organize later (or never).

## Tech Stack

- **Language:** TypeScript
- **Frontend:** React / Next.js
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL via Supabase
